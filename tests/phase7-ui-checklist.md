# Phase 7 — Checklist Desktop สำหรับผู้ใช้

สถานะ: **USER VERIFIED — 13 พฤศจิกายน 2026** ผู้ใช้ยืนยัน “UI Phase 7 ผ่านแล้ว” เป็นผลตรวจของผู้ใช้ ไม่ใช่ผล UI ที่ Agent รัน ไม่มีการทดสอบ Mobile; Checklist ด้านล่างเก็บไว้เป็นขั้นตอนอ้างอิง โดยไม่ได้รับผลแยกรายข้อ

เปิด `http://localhost/fixit/login.php` ด้วยบัญชี ADMIN เดิม เลือกเมนู **รายงาน** หรือเปิด `http://localhost/fixit/admin/reports.php`

- [ ] เมนูรายงานและลิงก์จาก Dashboard เปิดได้ หน้าแสดงตัวกรอง ตาราง และปุ่มครบบน Desktop
- [ ] ไม่ระบุวันที่แล้วกดแสดงรายงาน ได้ทุกช่วงเวลา ยอดสถานะรวมและยอดหมวดหมู่รวมเท่ากับคำร้องทั้งหมดตามตัวกรอง
- [ ] เลือกวันที่เริ่ม/สิ้นสุดเดียวกัน รวมคำร้องที่แจ้งตั้งแต่ 00:00 ถึงก่อนวันถัดไป ไม่กรองตามวันที่ส่งหลักฐานหรือวันปิดงาน
- [ ] เลือกวันเริ่มหลังวันสิ้นสุด ได้ข้อความแจ้งข้อผิดพลาด ไม่แสดงรายงานที่ทำให้เข้าใจว่าเป็นผลสำเร็จ
- [ ] กรองสถานะ/Priority/หมวดหมู่ร่วมกัน ยอดสรุปและรายการคำร้องใช้เงื่อนไขเดียวกัน ล้างตัวกรองกลับสู่ค่าเริ่มต้น
- [ ] รอนักศึกษายืนยันแสดงเป็นส่วนหนึ่งของกำลังดำเนินการ ไม่ต้องบวกเข้ายอดรวมอีกครั้ง
- [ ] เลือกช่างแล้วแสดงคำร้องที่ช่างนั้นรับมอบหมายปัจจุบันหรือเป็นผู้ส่งหลักฐานจริง ตารางช่างแยกสองจำนวนนี้ชัดเจน ไม่ให้เครดิตผู้รับงานใหม่แทนผู้ส่งเดิม
- [ ] เลือกช่วงที่ไม่มีคำร้องแล้วเห็น 0 และ Empty State โดยไม่มี error
- [ ] คลิกรายละเอียดคำร้องประกอบได้ถูกเลขคำร้องและกลับมาใช้ตัวกรองเดิมผ่าน Back ได้
- [ ] หากมีเกิน 25 คำร้อง ทดลองหน้าถัดไป/ก่อนหน้า ตัวกรองยังอยู่และยอดรวมไม่เปลี่ยน หากข้อมูลจริงมีไม่ถึง ไม่ต้องสร้างคำร้องจริงเพิ่มเพื่อทดสอบ ให้แจ้งว่าไม่มีข้อมูลพอสำหรับกรณีนี้
- [ ] ข้อความ/หัวข้อยาวยังอ่านได้ ตารางและ navigation ใช้งานบน Desktop ได้
- [ ] ถ้ามีข้อมูลผิดปกติ เห็นคำเตือนพร้อมจำนวนที่ตรงเหตุการณ์ โดยรายงานไม่แก้ assignment/confirmation เดิม ไม่ต้องดัดแปลงข้อมูลจริงเพื่อบังคับให้เกิดคำเตือน
- [ ] Login Student/Technician ต้องเปิดหน้ารายงาน Admin ไม่ได้ และการดูรายงานไม่เปลี่ยนสถานะ/ความสำคัญของคำร้อง

## ตัวเลขอ้างอิงจาก fixture ที่ Agent ทดสอบ

ตัวเลขนี้เป็นของฐานทดสอบ `fixit_test_*` ที่ runner สร้าง **ไม่ใช่จำนวนที่ต้องพบในฐาน fixit จริง** รายงานจริงขึ้นกับข้อมูลที่ผู้ใช้เปิด

ช่วงวันที่แจ้ง 28–29 กุมภาพันธ์ 2024 ใน fixture:

| รายการ | คาดหวัง |
|---|---:|
| คำร้องรวม | 5 |
| PENDING / IN_PROGRESS / COMPLETED / CANCELLED | 1 / 2 / 1 / 1 |
| LOW / MEDIUM / HIGH | 2 / 2 / 1 |
| หมวด 1 / หมวด 2 | 2 / 3 |
| รอยืนยัน (รวมใน IN_PROGRESS แล้ว) | 1 |
| รอมอบหมาย (เฉพาะ PENDING) | 1 |
| ช่าง #3 รับมอบหมาย / ส่งหลักฐาน / ยืนยันแล้วจากงานส่ง | 2 / 2 / 1 |
| ช่าง #5 รับมอบหมาย / ส่งหลักฐาน | 2 / 0 |

fixture ตั้งใจมีการมอบหมายซ้ำและเปลี่ยนช่างหลังส่งหลักฐานเพื่อทดสอบข้อมูลเก่า/ผิดปกติ จึงต้องเห็นคำเตือน และห้ามนำยอดช่างแต่ละคนมาบวกแทนยอดคำร้องรวม

เมื่อตรวจเสร็จ แจ้งรายการที่ผ่าน/ไม่ผ่าน พร้อมตัวกรองและตัวเลขที่พบ หากผ่านครบให้ยืนยันว่า **UI Phase 7 ผ่านแล้ว** เพื่อบันทึก USER VERIFIED และปิด Phase 7
